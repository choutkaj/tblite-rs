# tblite-rs 0.1.0

The first release provides `tblite`, a safe Rust interface to the tblite
extended tight-binding library, and `tblite-sys`, raw declarations for all
117 public C functions in tblite 0.7.0.

## Install

```toml
[dependencies]
tblite = "0.1.0"
```

Rust 1.85 or newer and a separately installed native **tblite 0.7.x** are
required. Cargo does not download or build Fortran. Follow the
[installation guide](https://github.com/choutkaj/tblite-rs/blob/v0.1.0/docs/installation.md)
to configure `TBLITE_DIR` or pkg-config and the native runtime library paths.

## Included

- GFN1-xTB, GFN2-xTB and IPEA1-xTB molecular and periodic calculations.
- Owned structures, calculators, contexts and results; reusable wavefunctions,
  geometry/charge/spin updates, custom parameters, tables and primitive arrays.
- Energies, gradients, virials, charges, multipoles, orbital data, matrices and
  post-processing dictionaries with documented shapes and atomic units.
- Solvation, electric fields, callbacks and optional native wavefunction I/O.
- Dynamic linking on Windows x86-64/MSVC, Linux x86-64 and macOS ARM64/x86-64.
  The `static` feature bundles tblite on Linux/macOS while external runtimes
  remain shared.

## Validation

The implementation passed CI on Linux with full and minimal native builds,
Windows/MSVC and both macOS architectures. Checks cover all 117 C symbols,
numerical references, finite-difference derivatives, ownership and callbacks,
static linking, Rust 1.85 and Linux native memory checks.

The recorded MB16-43 benchmark passes all **129 native/Rust calculation pairs**
on each of Linux and Windows: 43 geometries across three methods. This verifies
binding fidelity for the recorded builds, rather than accuracy against reference
reaction energies. See the
[benchmark reports](https://github.com/choutkaj/tblite-rs/tree/v0.1.0/benchmarks/mb16-43).

## Known limitations

- The API is an initial 0.1 release and may evolve in subsequent minor releases.
- Native calls are serialized; native handles are neither `Send` nor `Sync`.
  tblite can still use its internal OpenMP parallelism.
- ddX, HDF5 and TREXIO depend on the installed native build. Missing optional
  capabilities return native errors. TREXIO output and cross-compilation have
  not been validated.
- No optimizer/MD driver, prebuilt native binaries, Cargo-triggered native
  builds, Windows static linking or fully static executables are provided.
- The tblite 0.7.0 logger has a known small native allocation leak per used
  logger instance when replaced or destroyed. The memory checks suppress only
  that documented upstream leak. Other ABI adaptations and native limitations
  are described in the
  [safety notes](https://github.com/choutkaj/tblite-rs/blob/v0.1.0/docs/safety.md).
